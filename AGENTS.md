# Инструкции для прототипирования

Работай только в подрепозитории `Heartbeat-v2/design`. Выполняй команды из этого каталога и сохраняй
файлы в нём. Не используй клоны и не создавай дополнительные Git worktree.

По умолчанию работай в текущей ветке. Создавай ветки и переключайся на другие ветки только по явной
просьбе пользователя. Просьба сделать коммит или открыть PR сама по себе не разрешает создавать
или переключать ветки.

В IntelliJ IDEA открывай `Heartbeat-v2/design` через **File → Open** как самостоятельный проект.
В его окне **Commit** используется Git-привязка из `design/.idea/vcs.xml`.

1. Определи затронутые платформы и пользовательские сценарии. Зафиксируй результат оценки UI/UX в плане.
2. Если интерфейс меняется, примени скил [unslop](.agents/skills/unslop/SKILL.md) ([оригинал Дамира Соколовского](https://github.com/heydamir/unslop), CC BY 4.0). Проведи аудит по
   [списку признаков](.agents/skills/unslop/references/signs.md) и составь направление из пяти строк: продукт, характер, мир, моменты,
   сигнатура. Запиши направление в план и согласуй его с оператором до реализации.
3. Работай с макетами в [Pencil](https://www.pen.dev/) через Pencil MCP. Используй computer-use
   только для ручного открытия и сохранения файлов `.pen` в приложении. Сохрани `.pen` в `Heartbeat-v2/design`.
   Выполняй проходы unslop в макете по порядку: отступы, цвет, иконки, текст, типографика, компоновка, детали.
   Сборка HTML, снимки страниц, генерация изображений и story-видео к этапу макетов не относятся.
4. Покажи оператору основной сценарий и применимые состояния загрузки, отсутствия данных и ошибок.
   Укажи, где поведение различается между платформами.
5. При реализации и проверке Compose Multiplatform экранов применяй правила оформления из unslop.
   Механика HTML/CSS, снимки страниц и story-видео к Compose не переносятся.
6. Запиши согласованный вариант и путь к макету в плане. Опубликуй макет через PR в `Heartbeat-design`.
   После слияния PR передай SHA для обновления ссылки на подмодуль в Heartbeat-v2. При изменении
   согласованного сценария повторно согласуй его с оператором.

## Codex и Pencil

Для работы с макетом в Codex открой нужный `.pen` в Pencil, включи **Codex CLI** в **Settings → MCP**
и перезапусти Codex. Проверь, что в Codex доступен сервер `pencil`.
[Настройка подключения](https://docs.pencil.dev/getting-started/installation#chatgpt-and-codex)

В Codex, открытом из `Heartbeat-v2/design`, можно явно попросить агента `heartbeat_design`
проверить макет по спецификации и плану. Для ИИ-студии Aurora начни с
[исходного референса](plans/ai-studio-reference.md) и [плана с уточнениями](plans/ai-studio-aurora.md).
