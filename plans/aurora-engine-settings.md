# Настройка движков чата

Согласовано 21 ноября 2026. На широком экране одновременно видны разделы настроек, движки чата и редактор выбранной конфигурации. У копии общее с оригиналом подключение, собственные имя, настройки и правила. Макет находится на странице **Aurora · Engine sessings** в Aurora-DS. [Основной кадр Engine settings](https://www.figma.com/design/ivLmgulIBIkMzOw8sgvKxj/Aurora-DS?node-id=378-209215)

## Оценка UI/UX по референсам

- На первом снимке до установленных движков нужно пройти две иллюстрации режимов и общие разрешения. Следом идёт каталог на 42 позиции со своей прокруткой. Человеку, который пришёл изменить Claude, нужны лишь его название и вход в настройки.
- В строке каждого движка повторяется выбор режима. При единственном доступном режиме эта пара элементов занимает место у имени и статуса.
- На втором и третьем снимках форма раздвигает соседние строки. Модель приходится искать среди команды запуска, аргументов и переменных окружения. «Effort» и «Update» нарушают язык остальных подписей.

## Направление unslop

1. **Продукт.** Пользователь Heartbeat выбирает, чем вести новые диалоги, и настраивает конкретный движок.
2. **Характер.** Спокойный, точный, компактный.
3. **Мир.** Светлая рабочая область Aurora с теми же поверхностями и типографикой, что у чата.
4. **Моменты.** Выбор строки сразу показывает её настройки справа. При создании копии фокус переходит в поле имени.
5. **Сигнатура.** Имя, данное конфигурации, одинаково читается в списке движков, заголовке редактора и выборе движка в чате.

## Навигация и действия

Оператор задал три одновременно видимые зоны на широком экране и копирование движка с собственной конфигурацией или правилами.

| Зона | Содержимое и действие |
| --- | --- |
| Слева — список настроек | Над списком разделов постоянная кнопка «Назад в чат». Раздел «Движки» выделен на всём пути редактирования. |
| По центру — список движков | Под заголовком «Чат» залитая кнопка «+ Добавить движок», справа отдельная кнопка с лупой «Найти движок». Ниже добавленные движки и сохранённые копии. Подпись «Для новых чатов» отмечает конфигурацию по умолчанию. Когда появится терминал, выбор «Чат / Терминал» встанет над списком. |
| Справа — настройки движка | Заголовок с именем выбранной конфигурации и действие «Создать копию». Далее модель, усилие рассуждения при поддержке и режим доступа. «Правила» содержат текст инструкций для этой конфигурации. «Параметры запуска» раскрывают доступные в среде команду, аргументы и переменные. Изменения подтверждаются кнопкой «Сохранить». |

При первом входе выбрана конфигурация для новых чатов, при возврате — последняя выбранная строка, если она доступна. У списка и редактора своя прокрутка. «Добавить движок» открывает каталог с поиском в правой зоне. После добавления новая строка выделяется в центре, справа открываются её параметры.

### Окно, выход и поиск

На Windows в строке окна справа расположены сворачивание, разворачивание или восстановление и закрытие окна. На macOS слева расположены закрытие, сворачивание и переход в полноэкранный режим. Для реализации используются системные кнопки платформы. Полоса перетаскивания отделена от кнопок приложения.

«Назад в чат» закрывает настройки и возвращает к диалогу. При изменённом черновике доступны «Остаться», «Без сохранения» и «Сохранить и выйти». При ошибке сохранения редактор сохраняет значения для повтора.

Лупа раскрывает поиск по именам добавленных движков и копий в той же строке средней зоны. Поле получает фокус, список показывает совпадения, справа остаётся выбранная конфигурация. Стрелка слева от поля и Escape закрывают поиск и восстанавливают список. Кнопка с плюсом в обычном состоянии открывает каталог. На Android используются отдельные сенсорные кнопки высотой 48 dp.

## Копирование и выбор в чате

1. Пользователь выбирает Claude Code в центре и нажимает «Создать копию» справа. В правой зоне открывается черновик с именем «Claude Code — копия». Имя выделено для замены.
2. Копия использует тот же движок и подключение. Модель, режим доступа, поддерживаемые параметры запуска и текст правил получают исходные значения. Каждая сохранённая конфигурация дальше редактируется независимо.
3. Пользователь задаёт имя «Claude Code — ревью», выбирает режим «Только чтение» при его поддержке и вводит правило «При ревью сначала перечисли найденные проблемы». Правила задают инструкции агенту, фактические разрешения определяет режим доступа.
4. «Сохранить» добавляет одну строку рядом с исходной и выбирает её. «Отмена» возвращает к оригиналу. При переходе с изменённого черновика можно сохранить его, отбросить или продолжить редактирование.
5. В выборе движка чата доступны оба имени. По умолчанию новые чаты открываются с прежней конфигурацией. Копию можно выбрать для конкретного чата или явно назначить действием «Использовать для новых чатов».

## Платформы и состояния

| Ситуация | Что видит пользователь |
| --- | --- |
| Широкий Desktop, Windows и macOS | Три зоны рядом, редактор получает больше всего места. Смена строки в центре обновляет правую зону и сохраняет позицию списка. |
| Среднее окно | Общая навигация сворачивается в меню. Список движков и редактор остаются рядом, пока помещаются с текущим размером текста. |
| Android и узкое окно | Последовательный переход «Настройки → Движки → Параметры». Возврат восстанавливает строку. Изменение ширины сохраняет выбор и черновик. На Android цели касания от 48 dp. |
| Первая загрузка | В области списка отображается «Загружаем движки…». При повторной загрузке уже полученные строки остаются видны. |
| Пока пусто | «Пока нет движков для чата» и одно действие «Добавить движок». |
| Поиск без совпадений | «Движок не найден» и «Сбросить поиск». |
| Ошибка загрузки | В области списка — «Не удалось загрузить движки» и «Повторить». При сбое одного движка остальные строки доступны. |
| Ошибка сохранения | Причина и повтор сохранения в форме выбранного движка. Введённые значения сохраняются для исправления. |

В интерактивном примере нажать «Создать копию», затем поле имени, чтобы увидеть заполненный вариант «Claude Code — ревью». «Сохранить» выбирает новую строку. «Назад в чат» возвращает в диалог, где выбор конфигурации открывается из шапки. Сохранение сразу после создания показывает копию с исходными значениями. В примере поиска нажатие на поле или Enter подставляет запрос «Claude» и фильтрует список.

Структура трёх зон, переходы сценария и снимки проверены через Figwright. В макете использованы переменные светлой Aurora, стили типографики, экземпляры компонента режима доступа и основы Desktop-чата. Поля прототипа показывают подготовленные значения.
