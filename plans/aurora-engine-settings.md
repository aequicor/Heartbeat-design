# Настройка движков чата

Согласовано 21 ноября 2026. На широком экране одновременно видны разделы настроек, движки чата и редактор выбранной конфигурации. У копии общее с оригиналом подключение, собственные имя, настройки и правила. Макет находится на странице **Aurora · Engine sessings** в Aurora-DS. [Основной кадр Engine settings](https://www.figma.com/design/ivLmgulIBIkMzOw8sgvKxj/Aurora-DS?node-id=378-209215)

## Оценка UI/UX по референсам

- На первом снимке до установленных движков нужно пройти две иллюстрации режимов и общие разрешения. Следом идёт каталог на 42 позиции со своей прокруткой. Человеку, который пришёл изменить настройки агента, нужны лишь его название и вход в настройки.
- В строке каждого движка повторяется выбор режима. При единственном доступном режиме эта пара элементов занимает место у имени и статуса.
- На втором и третьем снимках форма раздвигает соседние строки. Модель приходится искать среди команды запуска, аргументов и переменных окружения. «Effort» и «Update» нарушают язык остальных подписей.

## Направление unslop

1. **Продукт.** Пользователь Heartbeat выбирает, чем вести новые диалоги, и настраивает конкретный движок.
2. **Характер.** Спокойный, точный, компактный. Один контурный значок обозначает агента и его копии.
3. **Мир.** Светлая рабочая область Aurora с теми же поверхностями и типографикой, что у чата.
4. **Моменты.** Выбор строки показывает доступные параметры сессии ACP. При создании копии фокус переходит в поле имени.
5. **Сигнатура.** Имя, данное конфигурации, одинаково читается в списке движков, заголовке редактора и выборе движка в чате.

## Навигация и действия

### Подключение ACP и профиль Heartbeat

Макет использует стабильный Agent Client Protocol v1. Профиль Heartbeat хранит имя, правила для диалога, выбранные значения параметров и ссылку на общее подключение. Копирование создаёт ещё один профиль с той же ссылкой. Поля запуска относятся к подключению, поэтому его изменение затрагивает все использующие его профили. На Android агент запускается на хосте подключения. Правила профиля передаются в контекст диалога средствами Heartbeat.

Для локального транспорта stdio у подключения задаются исполняемый файл, аргументы и переменные среды. При проверке клиент запускает процесс и выполняет `initialize`, согласует версию протокола, получает возможности агента и предложенные способы входа. При необходимости вход выполняется способом, который сообщил агент. [Инициализация](https://agentclientprotocol.com/protocol/v1/initialization) · [Транспорт](https://agentclientprotocol.com/protocol/v1/transports)

Поля сессии появляются по полученным `configOptions`. Клиент использует идентификаторы, типы, доступные значения и текущий выбор агента. При применении сохранённых предпочтений проверяет их актуальность, вызывает `session/set_config_option` и обновляет форму по ответу или уведомлению агента. При отсутствии опций доступны имя и правила профиля. Для агентов прежней версии, сообщающих только `modes`, можно показать их список. Режим сессии сам по себе не гарантирует уровень доступа к файлам. [Параметры сессии](https://agentclientprotocol.com/protocol/v1/session-config-options)

Оператор задал три одновременно видимые зоны на широком экране и копирование движка с собственной конфигурацией или правилами.

| Зона | Содержимое и действие |
| --- | --- |
| Слева — список настроек | Над списком разделов постоянная кнопка «Назад в чат». Раздел «Движки» выделен на всём пути редактирования. |
| По центру — список движков | Под заголовком «Чат» залитая кнопка «+ Добавить движок», справа отдельная кнопка с лупой «Найти движок». Ниже добавленные движки и сохранённые копии. Подпись «Для новых чатов» отмечает конфигурацию по умолчанию. Когда появится терминал, выбор «Чат / Терминал» встанет над списком. |
| Справа — настройки движка | Имя профиля, ссылка на общее подключение ACP, параметры сессии в составе, сообщённом агентом, и правила профиля. «Создать копию» открывает черновик. «Сохранить» записывает настройки профиля. |

При первом входе выбрана конфигурация для новых чатов, при возврате — последняя выбранная строка, если она доступна. У списка и редактора своя прокрутка. «Добавить движок» открывает каталог с поиском в правой зоне. «Подключить ACP-агента вручную» позволяет указать команду любого совместимого агента. После успешной проверки и добавления новая строка выделяется в центре, справа открываются её параметры.

### Окно, выход и поиск

На Windows в строке окна справа расположены сворачивание, разворачивание или восстановление и закрытие окна. На macOS слева расположены закрытие, сворачивание и переход в полноэкранный режим. Для реализации используются системные кнопки платформы. Полоса перетаскивания отделена от кнопок приложения.

«Назад в чат» закрывает настройки и возвращает к диалогу. При изменённом черновике доступны «Остаться», «Без сохранения» и «Сохранить и выйти». При ошибке сохранения редактор сохраняет значения для повтора.

Лупа раскрывает поиск по именам добавленных движков и копий в той же строке средней зоны. Поле получает фокус, список показывает совпадения, справа остаётся выбранная конфигурация. Стрелка слева от поля и Escape закрывают поиск и восстанавливают список. Кнопка с плюсом в обычном состоянии открывает каталог. На Android используются отдельные сенсорные кнопки высотой 48 dp.

## Копирование и выбор в чате

1. Пользователь выбирает Помощник в центре и нажимает «Создать копию» справа. В правой зоне открывается черновик с именем «Помощник — копия». Имя выделено для замены.
2. Копия ссылается на исходное ACP-подключение. Имя, предпочтения для доступных параметров сессии и правила сохраняются отдельно у каждого профиля.
3. Пользователь задаёт имя «Помощник — ревью», выбирает объявленный агентом режим «Обзор» и вводит правило «При ревью сначала перечисли найденные проблемы».
4. «Сохранить» добавляет одну строку рядом с исходной и выбирает её. «Отмена» возвращает к оригиналу. При переходе с изменённого черновика можно сохранить его, отбросить или продолжить редактирование.
5. В выборе движка чата доступны оба имени. По умолчанию новые чаты открываются с прежней конфигурацией. Копию можно выбрать для конкретного чата или явно назначить действием «Использовать для новых чатов».

## Платформы и состояния

| Ситуация | Что видит пользователь |
| --- | --- |
| Широкий Desktop, Windows и macOS | Три зоны рядом, редактор получает больше всего места. Смена строки в центре обновляет правую зону и сохраняет позицию списка. |
| Среднее окно | Общая навигация сворачивается в меню. Список движков и редактор остаются рядом, пока помещаются с текущим размером текста. |
| Android и узкое окно | Последовательный переход «Настройки → Движки → Параметры». Возврат восстанавливает строку. Изменение ширины сохраняет выбор и черновик. На Android цели касания от 48 dp. |
| Первая загрузка | В области списка отображается «Загружаем движки…». При повторной загрузке уже полученные строки остаются видны. |
| Пока пусто | «Пока нет движков для чата» и одно действие «Добавить движок». |
| Поиск без совпадений | «Движок не найден» и «Сбросить поиск». |
| Ошибка загрузки | В области списка — «Не удалось загрузить движки» и «Повторить». При сбое одного движка остальные строки доступны. |
| Ошибка сохранения | Причина и повтор сохранения в форме выбранного движка. Введённые значения сохраняются для исправления. |
| Агент ответил без параметров сессии | Имя и правила профиля доступны, раздел параметров показывает «Агент не сообщил настраиваемых параметров». |
| Проверка ACP | До ответа `initialize` клиент показывает проверку. При несовместимой версии или сбое запуска сообщает конкретную причину и предлагает исправить подключение. Успешный пример показывает согласованную версию. |

В интерактивном примере нажать «Создать копию», затем поле имени, чтобы увидеть заполненный вариант «Помощник — ревью». «Сохранить» выбирает новую строку. «Назад в чат» возвращает в диалог, где выбор конфигурации открывается из шапки. Сохранение сразу после создания показывает копию с исходными значениями. В примере поиска нажатие на поле или Enter подставляет запрос «Помощник» и фильтрует список.

Структура трёх зон, переходы сценария и снимки проверены через Figwright. В макете использованы переменные светлой Aurora, стили типографики, общий компонент значка агента и основу Desktop-чата. Поля прототипа показывают подготовленные значения.
