# Aurora: вложения по референсам Telegram

14 ноября 2026. Прямое уточнение оператора по четырём приложенным снимкам Telegram. Целевой файл — [aurora-new-chat.pen](../aurora-new-chat.pen). Правка выполняется в текущем согласованном оформлении Aurora.

## UI/UX и направление

Платформы: desktop и Android. Сценарии: получение файла в сообщении, подпись к вложению, открытие/загрузка/повтор, поиск файла в общем списке диалога. На desktop список файлов занимает правую панель; на Android — отдельный экран с возвратом в тот же диалог. Выбор следует предоставленным референсам.

1. Продукт: рабочий чат с файлами пользователя и результатами агента.
2. Характер: спокойный, компактный, узнаваемый.
3. Мир: файлы и рабочие записи в существующей палитре Aurora.
4. Моменты: миниатюра изображения и понятное имя документа.
5. Сигнатура: файл и подпись внутри общего облачка, одинаковая строка метаданных.

Аудит по unslop / signs: прежнее большое превью изображения, вложенные плашки документов и раздельные метаданные раздували сообщение. По прямой правке оператора заменяются компактной строкой файла. Цвет, типографика текста ответа и хронология агента сохраняются. Метод: unslop, Damir Sokolovsky, CC BY 4.0. Новое согласование направления не требуется: оператор задал конкретное оформление и референсы.

## Итоговые правила

- В сообщении: слева область 64 × 64; изображение заполняет её миниатюрой со скруглением 4. Документ получает круг 48 с пиктограммой 20, центрированный в той же области. Gap до текста 12.
- Справа: имя 14/20, вес 500; размер/состояние 12/16. Имя и метаданные начинаются на одной оси. Длинное имя переносится, расширение остаётся доступным; полное имя есть в доступном описании и меню.
- Вложение не получает ещё одну карточку внутри облачка. Несколько файлов идут вертикально с gap 8. Подпись 16/24 находится под файлами; время — внизу справа в том же облачке.
- Входные файлы и созданные результаты используют одинаковую визуальную строку. Artifact сохраняет конкретные действия «Посмотреть изменения» / «Открыть документ» / «Скачать»; просмотр не применяет патч.
- Готовое изображение открывает просмотр. Документ открывается доступным просмотрщиком; действие «Открыть с помощью…» показывается только при наличии такого сценария платформы. Оно не является обязательной английской надписью в макете.
- Загрузка: прогресс вокруг значка и числовой статус при наличии данных, остановка загрузки в той же области. Ошибка: красный признак и «Повторить», файл и подпись остаются. Недоступный файл не выглядит открываемым.
- В списке файлов: миниатюра/плитка типа 56, gap 12, строка от 80; имя 14/20, размер и дата 12/16. Тип различим расширением, цвет — дополнительный признак. Разделители начинаются под текстом. Группировка по месяцам, поиск, меню и переход к исходному сообщению.
- Палитра Aurora сохраняется: зелёный для готового файлового значка, сдержанные разные оттенки для PDF и текстовых плиток в списке. Ошибка отличается явным статусом, а не только цветом плитки.
- Hover выделяет целую строку нейтральным серым, клавиатурный фокус видим; touch не сохраняет hover. Цели от 32 desktop / 48 Android. Список файлов прокручивается независимо от диалога, возврат сохраняет позицию чтения.
- Markdown Image в содержимом ответа остаётся изображением документа; компактный файл не подменяет его. Черновые вложения у composer сохраняют возможность удаления до отправки.

## Проверка

Пройти лонгрид, состояния файлов, результаты агента и мобильный финал. Добавить примеры сообщения с документом/изображением, правой панели desktop и списка Android. Проверить переносы имени, оси, размер целей, отсутствие вложенных карточек и обрезаний. Анимации и файловые операции в Pencil остаются статическими состояниями и аннотациями.

Обновлены исходное сообщение `Scm9T`, состояния `f8OPB9`, файлы результата `HjvB9`, `anegA`, `Ji4Ce` и связанный Android-финал `QNxEY`. У Android-финала убрано прежнее дополнительное внутреннее поле файла; строки и действия имеют общий левый край текста.

Визуально проверены сообщения с изображением и PDF, длинное имя на Android, три состояния файла, desktop с панелью, Android-список и мобильный финал. Файлы и подписи остаются в одном облачке; отдельные плашки внутри сообщения удалены. Изображения в Markdown и экран просмотра сохранены. Кольцо загрузки показывает дугу без радиальных линий; неизвестный прогресс не заменяется процентом.

Подписи, размеры и даты в примерах — демонстрационные. Личные имена файлов и содержимое переписки со снимков Telegram в макет не перенесены. Работа выполнена через Pencil MCP; состав источников и аннотации сохранены в .pen. Публикация — существующий PR №7 текущей ветки.
