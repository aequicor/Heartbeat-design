# Проверка опросников и разрешений Aurora

Дата: 2026-11-15. Макет: [aurora-new-chat.pen](../aurora-new-chat.pen). Контракт: [единая панель](aurora-decision-panel.md).

## Область проверки

Через Pencil MCP выполнен обход всего документа с раскрытием экземпляров компонентов. Найдено 25 панелей; добавлено 6 недостающих мобильных образцов. Итоговая проверка — 31 панель, включая источники компонентов и экранные экземпляры: 23 опросника и 8 разрешений. 13 панелей мобильные. Проверены desktop, Android 320/390, IME и 200% текста.

## Исправления

- В варианте с открытой клавиатурой восстановлена навигация. Кнопки остаются над IME; нижний запас 16.
- Счётчик одиночных вопросов приведён к «1 из 1» и скрыт. В необязательных одиночных вопросах доступный «Пропустить» остаётся видимым; «Назад» скрыт.
- Добавлены Android 320: последний вопрос с «Отправить», локальная ошибка, разрешение, несколько вариантов, Confirm и выбор без свободного текста.
- Контракт и превью обновлены. Новое визуальное направление не вводилось.

## Результаты

| Требование | Результат |
|---|---|
| Title в шапке, без общей строки внимания | Во всех панелях |
| Нет subtitle, подписи над полем, «Снять выбор», футеров и повторных пояснений | Удалённые слои отсутствуют во всех 31 панелях |
| Description без подложки и внутренних полей, вторичный цвет | Все 8 разрешений используют `request.secondary` на прозрачном блоке |
| Последний/единственный вопрос — «Отправить» | Проверено, включая Android 320 |
| «Далее» и «Пропустить» ничего не отправляют | Закреплено в общем компоненте, контексте кнопки и контракте |
| «Назад» сохраняет все ответы; ответ снимает пропуск | Закреплено в навигации, поле, вариантах и контракте |
| Единый ответ набора, немедленный возврат ввода | `NrTfr` и кадр `GYFu0`; состояние отправки/ошибки принадлежит одному объекту истории |
| В панели только локальная ошибка, сверху | `IHJym` и `dE2xq`; ошибок отправки и повтора в активных панелях нет |
| Таймер останавливается при любом взаимодействии | Контракт и пара до/после фокуса; полоса остаётся на достигнутой длине |
| Разрешения без автоматического согласия | Прямые кнопки; полная неподвижная полоса во всех 8 экземплярах |
| Центральная ось навигации | Центр счётчика совпадает с центром строки во всех видимых полных pager |
| Touch-цели | Все видимые контролы мобильных панелей не меньше 48 × 48 |
| Обрезания | Непредусмотренных нет; в IME намеренно ограничена прокручиваемая область вариантов |
| Расположение листов | Листы вариантов не пересекаются после расширения |
