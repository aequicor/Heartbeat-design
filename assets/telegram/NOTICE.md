`background.svg` is the unmodified SVG decompressed from the source `.tgv` gzip file. It contains 745 paths with a 1440 × 2960 viewBox.

This artwork was used as a reference during the Telegram-style exploration. An earlier prototype embedded its geometry as 15 path groups, scaled to 720 × 1480, tinted #537C49 at 22% opacity.

The current `aurora-new-chat.pen` uses the separately generated Aurora work-themed pattern in `assets/aurora-chat/`. The Telegram component has been removed from the design. These files are retained only as source material for the documented reference study and are not required to render the current design.
