# Рабочий рисунок Aurora

Предметный рисунок создан в Pencil для рабочего чата Heartbeat: документы, папки, списки, терминальные окна и связи задач.

- E29XF6.svg — исходный векторный экспорт компонента 720 × 720.
- E29XF6.png — экспорт 2x для отображения в Pencil.
- INV9p.svg — актуальный бесшовный векторный оригинал, собранный в Pencil из цельных мотивов исходного рисунка. Предметы, пересекающие край, продолжаются с противоположной стороны.
- INV9p.png — его экспорт 2x для отображения в Pencil. Макет использует этот файл в режиме Multiply, непрозрачность 22%, размер плитки 720 × 720. Белая основа не осветляет зелёный фон.
- E29XF6.svg/png сохранены как исходный рисунок. Его края не образуют бесшовный повтор; для фона использовать INV9p.
- Сохраняйте эту папку рядом с aurora-new-chat.pen при переносе макета.

- cancellation-example.png — предоставленный оператором снимок прежнего интерфейса. Используется в демонстрационном диалоге как пользовательское вложение и иллюстрация исходного поведения; не является снимком реализации нового макета.
