# Aurora-DS — материалы переноса и резервная копия

Для текущей работы с Aurora-DS используй Figwright MCP по [AGENTS.md](../AGENTS.md).
Ниже описан перенос и его служебные скрипты Figwright.

Снимок переноса: 16 ноября 2026.

Именованная версия Figma: **Aurora · финальный Desktop · 16.11.2026**.
После локального сохранения резервная копия находится в
`exports/aurora-figma/Aurora-DS-final-2026-11-16.fig`. Контрольный PNG создаётся в
`exports/aurora-figma/compact/2-175087.png`. Оба пути отсчитываются от корня репозитория.

Визуальный источник — [Aurora-DS](https://www.figma.com/design/ivLmgulIBIkMzOw8sgvKxj/Aurora-DS?node-id=2-175087),
страница «Aurora · выразительный Desktop», кадр `2:175087`. Библиотека находится на странице
`2:8576`. После сверки 21 ноября 2026 рабочие состояния собраны на странице `2:175086`,
опорные кадры Android — на странице `305:162815`. Страница переноса `0:1` удалена.
[migration-state.json](migration-state.json) сохраняет историческое сопоставление ID;
часть перечисленных там узлов относится к предыдущей версии Aurora-DS.

## Содержимое пакета

- [aurora.json](aurora.json): цвета, типографика, геометрия и контрольные кадры прохода переноса.
- [migration-state.json](migration-state.json): ID страниц, переменных, исходных компонентов и общих стилей.
- [sync.mjs](sync.mjs): повторяемое обновление существующего Aurora-DS через Figwright 0.7.0.
- [compact-desktop.mjs](compact-desktop.mjs): завершающий проход компактной плотности Desktop;
  выполняется автоматически после общего sync. Контрольные кадры — `../exports/aurora-figma/compact/`.
- [desktop-components.json](desktop-components.json): 14 компонентов Desktop (8 инструментов,
  6 Thinking) и 42 экземпляра. Структуру меняет `desktop-tools.mjs`.
- `../exports/aurora-figma/`: локальная копия `.fig`, контрольные PNG и `sync-report.json`.
  Экспорты исключены из Git существующим правилом репозитория.

Исходный `aurora-new-chat.pen` оставлен как архив сценариев до переноса. Его повторный импорт
не восстанавливает доработки Figma. Для полного восстановления используйте актуальную `.fig`;
для дальнейшей работы — облачный Aurora-DS. Скрипт синхронизации не является импортёром `.pen`
и не пересоздаёт файл, страницы, компоненты или пользовательские данные.

## Исторический проход переноса через Figwright

Для воспроизведения прохода используй копию Figma и конфигурацию проекта из редакции 16 ноября. Текущие макеты правятся через Figwright MCP по инструкции в `AGENTS.md`.

1. Откройте Aurora-DS в Figma Desktop и запустите установленный плагин Figwright.
2. Запустите из корня дизайн-репозитория:

   ```sh
   node figma/sync.mjs
   ```

3. Скрипт проверит ID рабочего кадра, обновит общие стили Inter, компоненты инструментов
   и Thinking, оформление панелей, навигацию и непрерывные маски истории. Существующие
   имена, ID исходных компонентов, моноширинные фрагменты и семантические цвета сохраняются.
4. Сверьте PNG из `exports/aurora-figma` и отчёт. Сохраните именованную версию через
   **File → Save to Version History**, затем **File → Save local copy**.

Для скриптов требуются Node.js и установленный MCP-сервер Figwright. По умолчанию сервер
читается из `~/.local/share/figwright/server/node_modules/@figwright/mcp/dist/index.mjs`;
для другого расположения задайте `FIGWRIGHT_SERVER`. Один запуск обслуживает один файл;
не запускайте одновременно несколько экземпляров скрипта. После импорта `.fig` в другой
файл сначала проверьте ID и обновите ledger: скрипт намеренно не подбирает файл по сходству.

Для Desktop значения `desktopDensity` в `aurora.json` имеют приоритет над базовыми
`processStyles`, `navigation` и `chrome`. Базовые значения сохраняют мобильные и архивные
сценарии. Размер 14 в Figma переносится как `14.sp` в Compose, без пересчёта в печатные пункты;
системное масштабирование текста сохраняется. Touch-цели остаются не меньше 48.

На момент переноса стили находились в `Aurora/Desktop/Компактный/*`. Компоненты Desktop находятся на странице
`2:8576` под именами `Aurora/Desktop/Инструмент · строка/*` и `Aurora/Desktop/Thinking/*`.
Контрольные состояния: основной `2:175087`, пустой чат `2:55599`, ошибка отправки `2:56219`.
Старый каталог Thinking `2:94790` показывает базовые роли, а не компактную типографику Desktop.

Не переносите в код экспортные дубликаты истории как отдельные сообщения: это статическое
представление blur-маски Figma. В Compose нужна одна лента и визуальное перекрытие.
Сохраняйте привязку прокрутки при изменении метрик Inter и реальном переносе строк.
Проверяйте доступность Inter с кириллицей, загрузку семейства до измерения текста и лицензию
при включении шрифта в ресурсы приложения. Моноширинный код не переводится в Inter.

PNG подтверждает статическую композицию, но не работу scroll anchoring, hover/focus,
IME, клавиатуры и динамического масштабирования. Эти проверки выполняются при реализации.

В компактном Desktop инструмент занимает одну строку: иконка, название Regular 14,
серый статус `#5F6368` справа и шеврон. Подробности находятся в раскрытии. Thinking сохраняет
название и серый preview. Короткие пользовательские сообщения и короткие ответы подгоняются
по фактической ширине текста с полями 12; максимальная ширина пользовательского пузыря 520.
Высота строки инструмента — 32, промежуток событий — 2. Длинное название обрезается
многоточием; статус не переносится. Полное название и содержимое доступны в раскрытии.
